## Important behavior

- A correction appends a `ClinicalAmendment` record; it never rewrites the signed `ClinicalNote`.
- The original Doctor author is the only employee allowed to amend that initial assessment.
- Previous and corrected snapshots are generated by the server and stored as versioned JSON in the existing `previousContent` and `correctedContent` fields.
- The reason, author, and timestamp are mandatory. The server controls the author and timestamp.
- Amendment and audit rows are committed in the same Serializable transaction. Audit text does not contain clinical content or the amendment reason.
- No Doctor/Nurse UI or patient portal display is included in this API/data-layer increment.

Do not deploy or modify any remote environment as part of this local update. All project data must remain synthetic; MERUNO is not production clinical software.
